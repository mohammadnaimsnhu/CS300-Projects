In this project I worked on organizing course data and used different data structures and algorithms. The main problem was how to store course information and make it easy to sort, search and display in the correct order. I also needed to understand how different data structures affect performance.

I approached the problem by breaking it into smaller parts. I used different data structures like vectors, hash tables and binary search trees. This helped me compare how each one works. I learned that data structures are important because they change how fast and efficient a program is. Choosing the right structure helps improve performance and makes the program easier to manage.

I faced some challenges when I wanted to understand how each data structure worked. I overcame these problems by reviewing examples and testing my code step by step. Running the program and checking the output helped me find and fix issues. This made the learning process easier and more clear.

This project changed how I think about software design. I now focus more on planning before coding. I also think more about how data is stored and accessed. It is not only about making code work but also about making it efficient and organized.

This project also improved how I write programs that are maintainable and readable. I use clearer structure and separate different parts of the program. This makes the code easier to understand and update later. I also learned that good design helps reduce errors and improves long-term flexibility.
